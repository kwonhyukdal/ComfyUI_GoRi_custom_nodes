# GoRi 세팅 가이드

카메라 디렉터를 **처음 쓸 때 그대로 따라 하면 되는 값**을 정리했습니다.
직접 만져 보면서 감을 잡는 것이 가장 빠르고, 이 문서는 그 출발점입니다.

> 이 팩에는 지금 **카메라 디렉터 단독**이 들어 있습니다. (Consistency Keeper
> 노드는 개발 보류라 이 팩에 없습니다.)

---

## 1. 한 줄 요약

```
automation   = 규칙 (auto)        ← 키 없이 바로 동작
preset       = 시네마틱 인물 또는 제품 히어로
topic        = 하고 싶은 장면 한 줄 (한글 가능)
clip         = 최종 이미지 모델의 CLIP   ← 필수
image_1      = 참조 사진             (선택)
shot         = 중경 (MS) 이상        ← 얼굴이 중요한 컷
```

가장 짧은 경로는 **`topic` 에 장면을 한 줄 적고 `clip` 만 연결하는 것**입니다.
`prompt_in` 을 연결하지 않아도 노드가 topic 으로 프롬프트를 직접 만듭니다.

```text
topic      "창가에 앉아 있는 여성, 따뜻한 오후"   (한글 그대로)
clip       최종 모델의 CLIP
image_1    (선택) 참조 사진
```

---

## 2. 처음 한 번 해 보는 순서

```
1  카메라 디렉터를 놓는다
2  automation = 규칙 (auto), preset = 시네마틱 인물
3  topic 에 장면을 한 줄 적는다 (한글 가능)
4  clip 에 최종 모델의 CLIP 을 연결한다
5  (선택) 참조 사진을 image_1 에 연결한다
6  실행하고 prompt_out 을 Show Text 로 열어 실제 문장을 확인한다
```

**얼굴이 중요한 컷은 `shot`을 `중경 (MS)` 이상으로 두세요.** `자동`은 전신이
잡혀 얼굴이 작아질 수 있습니다.

이 상태에서 결과가 원하는 구도·분위기와 얼마나 맞는지가 기준점입니다.
여기서부터 아래 표를 보며 한 칸씩 조절하세요.

---

## 3. 증상별 조절

| 증상 | 먼저 볼 것 | 조절 |
|---|---|---|
| 얼굴이 참조와 다름 | 참조 이미지 | 같은 인물의 참조를 `image_1` 에 연결 |
| 얼굴이 작아서 닮지 않음 | 카메라 `shot` | 전신 대신 `중경 (MS)` 이상 |
| 구도·조명이 마음대로 | 카메라 10칸 | `자동` 대신 프리셋·직접 선택으로 고정 |
| 매 컷 룩이 달라짐 | 카메라 10칸 | `자동` 대신 프리셋·직접 선택으로 고정 |
| 포즈를 바꾼 뒤 얼굴이 달라짐 | 토픽의 포즈 문장 | 얼굴이 중요하면 포즈 문장을 빼고 다시 실행 |
| 참조 신발과 다른 신발이 나옴 | 토픽 | 원하는 색·스타일을 토픽에 직접 적기 |
| 배경 사물이 반투명하게 겹침 | 참조 구도 | 결과와 같은 구도로 참조를 준비 |
| 참조가 결과에 거의 반영되지 않음 | sampler `denoise` | `denoise` 를 0.6~0.8 로 낮춤 (아래 5절) |
| 참조 배경의 바닥·광원이 안 따라옴 | 토픽의 배경 선언 | `4번: 배경` 처럼 콜론으로 배경을 선언. 조명은 자동이면 참조를 따르고, 직접 고르면 고른 값이 우선 (아래 4절 · 상세 5-8) |

카메라 10칸은 **한 번에 하나씩** 바꾸세요. 여러 칸을 동시에 바꾸면 어느 쪽이
효과를 냈는지 알 수 없습니다.

## 4. 카메라 쪽에서 결과가 크게 바뀌는 것

| 바꾸면 큰 변화 | 바꿔도 작은 변화 |
|---|---|
| 샷 크기 (중경 → 극접) | 렌즈 길이 (35mm ~ 200mm) |
| 앵글 (수평 → 로우앵글, 편각) | 그레이드 세부 종류 |
| 장면을 LLM이 다시 쓴 경우 | `speed`·`amplitude` 단독 변경 |

- **렌즈는 결과 차이가 작습니다.** 구도가 안 맞으면 렌즈보다 샷과 앵글을 보세요.
- **`AI 판단 (llm)`은 장면을 다시 씁니다.** 규칙 모드와 결과가 다를 수 있습니다.
  키가 없거나 네트워크가 끊기면 자동으로 규칙으로 돌아갑니다.
- **룩을 고정하려면 `자동`을 쓰지 마세요.** `자동`은 입력 이미지의 밝기·채도에
  따라 조명과 색보정을 바꿉니다. 시리즈물은 프리셋이나 직접 선택으로 고정합니다.
- **포즈를 지시하면 얼굴도 새로 그려집니다.** `앉아`, `걷고 있다` 같은 문장이나
  포즈 맵을 쓰면 모델이 몸과 함께 얼굴도 다시 그립니다. 얼굴이 중요한 컷은
  토픽에 포즈를 쓰지 마세요.
- **참조 배경을 쓰면 표면은 참조를 따릅니다.** `4번: 배경` 처럼 선언한 참조의
  바닥 재질·벽·러그는 그대로 유지됩니다. 조명은 조명 칸이 `자동`일 때 참조 배경
  광원을 따르고, 조명·그레이드를 직접 고르면 고른 값이 1순위입니다 — 카메라
  설정이 참조에 덮이지 않습니다 (`README.md` 5-8).

## 5. 자주 하는 실수

```
프리셋을 고른 뒤 드롭다운 하나만 바꿈
   -> 그 칸만 바뀌고 나머지는 프리셋 값 그대로입니다.
      항목을 더하면 프리셋 값에 합산되고, 그 칸을 '자동'으로 되돌리면
      그 칸만 프리셋에서 빠집니다

denoise 를 1.0 으로 두고 참조를 살리려 함
   -> 원본 픽셀을 거의 쓰지 않습니다. 참조를 살리려면 0.6~0.8 을 쓰세요
      (단, 비율·구도를 바꾸는 워크플로에서는 1.0 이 정상일 수 있습니다)

포즈를 topic 에 적고 얼굴이 그대로이길 기대함
   -> 포즈를 바꾸면 모델이 얼굴도 새로 그립니다. 얼굴 유지가 목적이면
      topic 에 포즈를 쓰지 말고 배경·소품만 바꾸세요

pose_image 에 손·얼굴까지 그린 맵을 넣음
   -> 점이 겹쳐 자세를 잘못 읽을 수 있습니다. 몸만 그린 맵을 연결하세요

clip 에 최종 모델이 아닌 다른 CLIP 을 연결함
   -> 얼굴과 피부가 깨질 수 있습니다. 최종 이미지 모델의 CLIP 을 쓰세요
```

## 6. 설정을 더 만질 필요가 없을 때

아래는 **바꿔도 얻는 것이 거의 없는** 항목입니다.

- **렌즈 길이** — 구도가 아니라 화각만 살짝 바뀝니다.
- **노드가 정한 판정 기준** — 건드리면 오히려 조용히 나빠집니다.
- **프리셋을 더 잘게 나누기** — 지금 있는 5종으로 충분합니다.

반대로 **효과가 큰 순서**는 샷 → 앵글 → 조명 → 그레이드입니다.

---

## 7. 직접 확인하는 법

이 문서의 값은 출발점일 뿐입니다. 기기와 모델이 다르면 결과도 다릅니다.

```
1  같은 원본·같은 시드로 두 번 실행한다 (프리셋 A / 프리셋 B)
2  두 결과를 나란히 놓고 얼굴·손·구도를 본다
3  원본에 더 가까운 쪽이 그 값이 맞는 것이다
4  차이가 거의 없으면 다른 한 칸을 바꿔 다시 본다
```

"개선됐는지"는 결국 눈으로 판정하는 것입니다. 숫자보다 **원본과 나란히
놓고 보는 것**이 가장 정확합니다.
